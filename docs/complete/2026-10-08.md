## 축의금 접수 문제 수정

- `gift/index.html`
  - 기기 구분값(`D-XXXX`)을 만들어 전송 데이터에 포함 → 기기 간 순번 충돌 방지
  - 삭제 시 뒷번호를 당기지 않음, 삭제 전 확인창 추가
  - 전체 초기화 시 봉투 번호를 0으로 되돌리지 않음 (시트 기록은 유지)
  - 미전송 대기열(`localStorage`) 추가: 실패 시 `미전송 N건` 표시, 다시 보내기 버튼, 온라인 복귀·30초마다·접속 시 자동 재전송
- `google-apps-script/rsvp.gs`
  - 축의금 행을 `기기 + 순번`으로 탐색, `기기` 열 추가 (기존 탭은 제목만 자동 보충)
  - 같은 건의 재전송(add)은 새 행 대신 기존 행 갱신
  - 삭제 시 다른 행 순번 변경 제거
  - RSVP 전화 뒤 4자리를 텍스트로 저장해 앞자리 0 유지
- `README.md`: 축의금 동작 설명 갱신, Firebase 항목의 예전 RSVP 설명 정리
- 검증: 두 파일 문법 검사, 접수 화면 등록·오프라인·삭제·복구·초기화 흐름 시뮬레이션 통과
